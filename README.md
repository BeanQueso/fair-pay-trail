Fair Pay Trail, built by Eshaan (BeanQueso) and Matt (oumatthew11), is a mobile-first web app that helps workers organize evidence of possible wage theft into a clear case. The project was designed to advance UN Sustainable Development Goal 8: Decent Work and Economic Growth, particularly its focus on protecting labor rights and promoting fair working conditions. It uses Supabase for authentication, PostgreSQL database storage, private file storage, Row Level Security, and Edge Functions, and the Groq API for AI-powered document extraction and case analysis. Core features include secure evidence uploads, extracted facts, case timelines, possible pay-discrepancy detection, missing-evidence guidance, recommended next steps, and case-packet support. The frontend is built in Lovable and connected to Supabase through @supabase/supabase-js.
