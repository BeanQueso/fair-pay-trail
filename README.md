Fair Pay Trail, built by Matt (oumatthew11) and I (BeanQueso) is a mobile-first web app that helps workers organize evidence of possible wage theft into a clear case. It uses Supabase for authentication, PostgreSQL database storage, private file storage, Row Level Security, and Edge Functions. It uses the Groq API for AI-powered document extraction and case analysis, including OCR for images and structured reasoning across multiple evidence files. Core features include secure evidence uploads, extracted facts, case timelines, possible pay-discrepancy detection, missing-evidence guidance, recommended next steps, and case-packet support. The frontend is built in Lovable and connected to Supabase through @supabase/supabase-js.
